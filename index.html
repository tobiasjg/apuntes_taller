Git

Git es un sistema de control de versiones distribuido. Sirve para rastrear todos los cambios que se realizan en el código de un proyecto, permitiendo guardar el historial de modificaciones, recuperar versiones anteriores y colaborar en equipo sin perder información ni sobreescribir el trabajo de otros.

¿Por qué es tan útil usar Git?

  • Historial completo: Funciona como una máquina del tiempo. Puedes ver exactamente qué se modificó, quién lo hizo y cuándo.
  • Trabajo en equipo sin caos: Permite que varias personas trabajen en el mismo proyecto simultáneamente.
  • Copias de seguridad: Cada miembro del equipo tiene una copia completa del proyecto y su historial.
Comando Descripción
git init Inicializa un repositorio Git creando la carpeta oculta .git.
git config user.name Muestra el nombre de usuario configurado en Git.
git config user.email Muestra el correo electrónico configurado en Git.
git status Muestra el estado actual de los archivos del proyecto.
git add . Agrega todos los cambios al área de preparación (staging).
git commit -m "mensaje" Guarda los cambios con una descripción.
git add . sirve para pasar los archivos a zona de modificacion o seleccionarlos. el punto nos permite seleccionar todos los archivos.

GitHub

GitHub es una plataforma en la nube utilizada por desarrolladores para almacenar código fuente y colaborar en proyectos de software. Funciona como una red social para programadores y un sistema de control de versiones.

¿Qué hace exactamente?

  • Aloja código en repositorios: Funciona como un disco duro en internet para guardar proyectos.
  • Control de versiones: Permite guardar distintas versiones del código y volver atrás si es necesario.
  • Trabajo colaborativo: Facilita que varios desarrolladores trabajen juntos en un mismo proyecto.
