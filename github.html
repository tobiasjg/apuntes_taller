git

Git es un software de control de versiones diseñado para registrar todos los cambios realizados en el código fuente de un proyecto. Funciona como una "máquina del tiempo" y un sistema de respaldo inteligente, permitiendo a los desarrolladores volver a versiones anteriores, trabajar en equipo sin sobreescribir el trabajo ajeno y experimentar con nuevas funciones de forma segura

github

GitHub es una plataforma en la nube utilizada para almacenar, compartir y trabajar en equipo en proyectos de software
